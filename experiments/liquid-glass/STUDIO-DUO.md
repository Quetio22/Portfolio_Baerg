## Proposition réalisée pour Baerg

Un diptyque crème/orange partage un point de liaison. Quand une carte prend le focus visuel, l’autre répond par un léger mouvement inverse ; le point commun accompagne ce transfert. Cette interaction est une création pour Baerg inspirée des relations graphiques des références, pas la reproduction d’une animation vérifiée du Vault.

Les titres et paragraphes existants sont conservés. L’ajout « Design — Développement » est décoratif. Les boutons permettent de fixer une sélection sans masquer de contenu. Le survol et le focus donnent un aperçu temporaire ; Échap ou un second clic réinitialise. Sur petit écran, la liaison devient verticale et les cartes restent immobiles. La préférence de mouvement réduit supprime les transitions.

Le CSS et le JavaScript sont chargés uniquement sur À propos. Les autres pages reçoivent uniquement le traitement des actions demandé. Le Lab, le Vault, les maquettes de projets, les URL et la logique du formulaire restent intacts.
